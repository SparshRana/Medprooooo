# Pilot protocol — not completed research

No participants, pharmacist endorsements, real-world outcomes or OCR accuracy figures are claimed.

Invite 5–10 consenting families, including older adults, and 2–3 registered pharmacists. Start with synthetic packs and never interrupt treatment. Store identifiable consent records outside GitHub.

Tasks: register one pack; distinguish a no-match from an exact historical finding; identify one affected batch among two similar packs; use Dadi Mode without coaching; explain the next action; prepare a pharmacist review; register a replacement strip; handle failed updates and offline reconnection.

Measure task completion, time, corrections, abandonment, comprehension and need for assistance. Evaluate Hindi transcripts separately from installed-voice availability. Ask pharmacists to identify missing information and workflow friction.

For the manual baseline, use a separate equivalent pack and the official portal; counterbalance task order. Report sample sizes, failures and median task times. Do not turn prototype metrics into avoided injuries or clinical effectiveness.

For OCR, create a consented, de-identified labelled photo set spanning pack formats, blur, glare, dates, punctuation and look-alike characters. Hold out cases from parser changes. Measure exact accuracy per field, abstentions and correction rates. Synthetic transcript tests do not measure OCR accuracy.

Never commit patient names, prescriptions, photographs, health histories or contact details to this public repository.
